# Agent 写作备忘

## 文章类型对应的审阅重点和遵照规范文档

| 文章类型               | 审阅重点                                       | 遵照规范文档                                                                                             |
| ---------------------- | ---------------------------------------------- | -------------------------------------------------------------------------------------------------------- |
| 编程、计算机、游戏技术 | 概念准确、边界明确、可复现，区分事实与设计选择 | [当前状态文档写作规范](当前状态文档写作规范.md)、[中文技术写作语义审校清单](中文技术写作语义审校清单.md) |
| 投资分析               | 证据可追溯，区分事实、假设、推断及不确定性     | 暂定：[通用写作规范](通用写作规范.md)                                                                    |
| 生活建议               | 结合实际约束，明确行动建议与适用条件           | 暂定：[通用写作规范](通用写作规范.md)                                                                    |
| 人际关系               | 区分事实与主观解读，避免替他人推断动机         | 暂定：[通用写作规范](通用写作规范.md)                                                                    |
| 哲学思辨               | 定义清晰、推理有效、处理反例与不同立场         | 暂定：[通用写作规范](通用写作规范.md)                                                                    |
| 项目简历、面试         | 结果可验证，个人贡献明确，叙述与证据一致       | 暂定：[通用写作规范](通用写作规范.md)                                                                    |

“暂定”表示该文章类型尚无专用规范，暂按通用写作规范审阅，并结合本表的审阅重点。表中未列出的文章类型同样按通用写作规范审阅。
当前状态文档写作规范以通用写作规范为基准，选用它时两份都要遵循。

## Agent 分层编辑和审阅

Agent 编辑和审阅文档时，按以下三个层次检查质量：

| 层次     | 解决的问题                                                      | 主要手段                                  |
| -------- | --------------------------------------------------------------- | ----------------------------------------- |
| 格式质量 | 文件名、Markdown 结构、中文排版、拼写、格式、术语与链接是否合规 | [Markdown 审计入口](Markdown-审计入口.md) |
| 内容质量 | 事实是否准确，信息是否完整，是否存在过期表述                    | Agent 语义审校                            |
| 编辑质量 | 文章是否连贯、简洁、自然，能否满足特定读者的阅读需求            | 以目标读者视角通读全文复审                |

编辑和审阅均以文档的四个核心为依据，检查内容是否服务于目标读者和用途、是否覆盖核心范围，以及是否超出明确排除的范围。
需要修改四个核心时，先只修订 frontmatter 并说明变更，随后必须中断正文修订，等待真实人类操作者的显式授权；获得授权后再据文档当前的四个核心修订正文。

这里的“真实人类操作者的显式授权”，须由真实人类操作者针对具体变更或方案明确作出。多 Agent 场景中，主 Agent、子 Agent 或其他 Agent 的同意、自我确认及工具返回的批准状态均不能代替该授权；沉默、等待超时或未提出异议也不构成授权。已有授权明确覆盖当前变更时，无须重复请求。
