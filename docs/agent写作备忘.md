# Agent 写作备忘

以 [通用写作规范](通用写作规范.md) 为基础，按下表确定各类文章的审阅重点。涉及当前有效方案或约束时，另参照 [当前状态文档写作规范](当前状态文档写作规范.md)。

## 各类文章的审阅重点

| 文章类型               | 审阅重点                                                                                                       |
| ---------------------- | -------------------------------------------------------------------------------------------------------------- |
| 编程、计算机、游戏技术 | 概念准确、边界明确、可复现，区分事实与设计选择，并对照 [中文技术写作语义审校清单](中文技术写作语义审校清单.md) |
| 投资分析               | 证据可追溯，区分事实、假设、推断及不确定性                                                                     |
| 生活建议               | 结合实际约束，明确行动建议与适用条件                                                                           |
| 人际关系               | 区分事实与主观解读，避免替他人推断动机                                                                         |
| 哲学思辨               | 定义清晰、推理有效、处理反例与不同立场                                                                         |
| 项目简历、面试         | 结果可验证，个人贡献明确，叙述与证据一致                                                                       |

## Agent 分层编辑和审阅

编辑和审阅均以文档的四个核心为依据，检查内容是否服务于目标读者和用途、是否覆盖核心范围，以及是否超出明确排除的范围。需要修改四个核心时，按通用规范先经人工确认，再据此修订正文。

| 层次     | 解决的问题                                           | 主要手段                                  |
| -------- | ---------------------------------------------------- | ----------------------------------------- |
| 格式质量 | Markdown 结构、中文排版、拼写、术语与链接是否合规    | [Markdown 审计入口](Markdown-审计入口.md) |
| 内容质量 | 事实是否准确，信息是否完整，是否存在过期表述         | Agent 语义审校                            |
| 编辑质量 | 文章是否连贯、简洁、自然，能否满足特定读者的阅读需求 | 以目标读者视角通读全文复审                |

- 使用 Agent 审阅文档时，应开启全新上下文，并提供全文、已确认的 frontmatter、适用规范和必要证据，减少先前修订思路对判断的影响。
- 定期清理正文中已失效的修订说明；有保留价值的历史信息应标明适用时间或移入历史记录，不删除仍有用的事实与证据。
