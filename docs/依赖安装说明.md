# 依赖安装说明

本文只安装 `tools/docs-audit/package.json` 中声明的 npm 依赖。Node.js、Git 和其他检查工具由本机预置，本文不提供它们的安装步骤。

## 安装 npm 依赖

`package.json` 只声明以下两个开发依赖：

| 依赖     | 固定版本 |
| -------- | -------- |
| CSpell   | 10.3.6   |
| Prettier | 3.9.9    |

在 wenlab 根目录执行：

```text
cd tools/docs-audit
npm ci --registry=https://nexus.home.arpa/repository/npm-group/ --ignore-scripts --include=dev
cd ../..
```

`npm ci` 使用现有的 `package-lock.json` 安装上述固定版本。命令显式指定 Nexus npm Group，并禁用安装期生命周期脚本。Nexus 缺少制品或不可访问时，记录包名、版本、仓库和错误后停止，不切换其他 Registry。

## 本机预置工具

以下工具不在 `package.json` 中，应已经在当前机器上预置。原生工具由 Gate 先查 `tools/docs-audit/bin/`，再查 `PATH`；本文不负责安装或升级：

| 工具        | 要求版本 |
| ----------- | -------- |
| Node.js     | 22.18.0+ |
| Git         | 可用即可 |
| AutoCorrect | 2.16.3   |
| rumdl       | 0.3.0    |
| Vale        | 3.24.0   |
| lychee      | 0.24.2   |

## 检测依赖

安装 npm 依赖后，在 wenlab 根目录运行：

```text
node ./tools/docs-audit/Check-Dependencies.mjs
```

脚本只读取依赖和版本，不安装、不升级，也不访问网络。每项输出 `PASS` 或 `FAIL` 及实际版本和来源：

- 退出码 0：Node.js、Git、CSpell、Prettier 和四个原生工具均可用且版本符合要求。
- 退出码 1：至少一项缺失或版本不符。按输出提示补充本机环境，或重新执行本文的 Nexus 安装命令。
