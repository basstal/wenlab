# 依赖安装说明

本文说明如何安装 `tools/docs-audit/package.json` 中声明的 npm 依赖，并检测 Node.js、Git 和本机原生工具是否可用。Node.js、Git 和其他检查工具由本机预置，本文不提供它们的安装或升级步骤。

本文以公网 npm Registry 可用为前提编写，安装时不使用 `tools/docs-audit/package-lock.json`。锁文件中的下载地址指向仓库作者的本地 Nexus 仓库，公网环境无法访问。

## 安装 npm 依赖

`package.json` 只声明以下两个开发依赖：

| 依赖     | 固定版本 |
| -------- | -------- |
| CSpell   | 10.3.6   |
| Prettier | 3.9.9    |

在 wenlab 根目录执行：

```text
cd tools/docs-audit
npm install --no-package-lock --registry=https://registry.npmjs.org/ --ignore-scripts --include=dev
cd ../..
```

- `--no-package-lock` 让 npm 忽略现有的 `package-lock.json`，也不改写它。CSpell 和 Prettier 按 `package.json` 安装上述固定版本；它们的间接依赖从公网 Registry 重新解析，版本可能与锁文件不同。Gate 和依赖检测脚本只核对 CSpell、Prettier 自身的版本。
- `--registry` 显式指定公网 npm Registry，避免本机 npm 配置中的镜像或私有仓库影响安装来源。
- `--ignore-scripts` 禁用安装期生命周期脚本，CSpell 和 Prettier 的运行不依赖这类脚本。

## 本机预置工具

以下工具不在 `package.json` 中，应已在当前机器上预置。Gate 先在 `tools/docs-audit/bin/` 查找原生工具，再查 `PATH`。

| 工具        | 要求版本 |
| ----------- | -------- |
| Node.js     | 22.18.0+ |
| Git         | 可用即可 |
| AutoCorrect | 2.16.3   |
| rumdl       | 0.3.0    |
| Vale        | 3.24.0   |
| lychee      | 0.24.2   |

## 检测依赖

安装 npm 依赖后，在 wenlab 根目录运行：

```text
node ./tools/docs-audit/Check-Dependencies.mjs
```

脚本只读取依赖和版本，不安装、不升级，也不访问网络。每项输出 `PASS` 或 `FAIL` 及实际版本和来源：

- 退出码 0：Node.js、Git、CSpell、Prettier 和四个原生工具均可用且版本符合要求。
- 退出码 1：至少一项缺失或版本不符。按输出提示补充本机环境，或重新执行本文的安装命令。
